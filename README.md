# POGPOVChanger

A Pit of Goblin mod that lets players toggle between first-person and third-person camera views.

## Default keybind

The mod defaults to the F5 key. If POG Config is installed, a custom POV toggle key can be assigned from the in-game config menu.

## Mod details

- Project: POG-POV-Changer
- Author: GlitchApotamus

## WARNING

Use this mod at your own risk! There are no animations and you can't interact with anything while in 3rd person! You can change back to 1st person to get everything working again.
Everything will be fixed after version 1.0 POG!
